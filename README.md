# Blog Application

A dynamic Blog Application developed using HTML, CSS, JavaScript, Node.js, Express.js and Supabase.

## Features

- User Registration and Login
- Supabase Authentication
- Secure User Authentication using Access Token
- Create and Publish Blogs
- Retrieve All Blogs from Database
- View Individual Blog Details
- Supabase Database Integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Supabase
- GitHub
